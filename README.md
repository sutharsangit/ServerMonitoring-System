# Server Monitoring System

## 📌 Overview

The Server Monitoring System is designed to monitor system conditions and display real-time data through a dashboard. It provides alerts and notifications to help maintain system stability and performance.

---

## 🚀 Features

* Real-time monitoring of system parameters
* Dashboard visualization using web interface
* Alert notifications via SMS
* Scalable backend integration
* Modular architecture for easy extension

---

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/ServerMonitoring-System.git
```

### 2. Navigate to project

```
cd ServerMonitoring-System
```

### 3. Setup Backend

```
cd Backend
python app.py
```

### 4. Setup Frontend

```
cd Frontend
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file in the Backend directory and add:

```
TWILIO_ACCOUNT_SID=your_sid
TWILIO_AUTH_TOKEN=your_token
```
